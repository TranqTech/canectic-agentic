# Canectic BBS

A BBS for the modern world and beyond.

## Features:
- A modern event-driven terminal server
- Support for both CP437 and UTF8
- Wide terminal formatting and auto-scaling/positioning
- Built-in door server
- Websockets and other modern connection methods
- Modern Web Forum views and features
- A mix of legacy, modern, and experimental message networking technologies

## Package requirements not in NPM (apt)
- build-essential
- python3
