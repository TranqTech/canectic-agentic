# Canectic BBS v0.9.0-alpha.1 "Handshake"

**First public alpha release** - feature-complete for community testing.

## What is Canectic BBS?

A modern Bulletin Board System built with Node.js, offering both terminal (ANSI/CP437/UTF-8) and web interfaces. Supports door games, file areas with native transfer protocols, three message networking protocols, and internet email integration.

## Highlights

### Terminal

- ANSI/CP437 and UTF-8 with auto-detection and wide terminal support
- Hotkey menus with configurable colors and layout
- Threaded message reader with scrolling viewport and quoting
- Full-screen message editor with word wrap and quote system
- File browser with native XMODEM and ZMODEM engines, batch downloads
- Door game support: native shell, DOS (dosemu2), Synchronet JS shims
- Private messaging with multi-transport compose
- Announcement viewer with scrolling and navigation

### Web

- Responsive web forum with Bootstrap 5 Darkly theme
- File browsing, download, and upload with hash verification
- Webmail-style private messaging (split-pane inbox)
- 6-step registration wizard with AJAX validation
- Landing page with announcement/bulletin system
- User profile page
- Full admin dashboard with CRUD for all system entities

### Networking

- **FTN** - Type-2 packet tosser, binkp mailer (TCP + WebSocket), BSO scanner, nodelist import/routing
- **QWK** - Client pull/push and hub mode
- **NNTP** - Article pull/push
- **TIC** - File echo distribution with auto-forwarding
- **Email** - Outbound via SMTP relay, inbound via trusted gateway

### Mail Client Access

- IMAP4rev1 and SMTP submission servers for PM access from Thunderbird, etc.
- Multi-transport addressing (.ftn, .qwk, external email domains)
- Cross-process IMAP IDLE push notifications

### Infrastructure

- Four-process model (gateway, worker, mail, mailer) managed by PM2
- BullMQ job queues with scheduled toss cycles and maintenance
- Three-tier configuration (.env > database > defaults) with admin UI
- CSRF protection, startup validation, health check endpoint
- Declarative database migrations
- Install/update script for deployment

## Getting Started

Download the release source code and extract, or clone the release repo:

```bash
git clone --branch v0.9.0-alpha.1 --depth 1 https://gitlab.tranqsoft.com/drog007/canectic.git
cd canectic
bash setup/install.sh
```

See `docs/sysop/INSTALL.md` for the full walkthrough.

The first registered user is automatically promoted to Sysop.

## Requirements

- Node.js 18+
- PostgreSQL 14+
- Redis 6+
- Linux (Debian/Ubuntu recommended)
- System packages: `build-essential python3 zip lrzsz`

## Known Issues

- ZMODEM file transfers fail with IcyTerm (both directions); all other tested clients work
- User profile page is read-only (no edit/settings yet)
- Password reset sends a PM but lacks a token/link flow

## Roadmap to 1.0

- Email/netmail address verification
- Door server BBS registration integration
