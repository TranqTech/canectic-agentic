# Canectic BBS v0.9.1-alpha.1

**Web doors, terminal scaling, user verification, password reset.**

## Highlights

### Web Door Launcher

Play door games directly from a web browser. An xterm.js embedded terminal connects via WebSocket with server-generated one-time tokens - no client-side credentials exposed. The terminal renders at fixed 80x25 with auto-scaling font in a centered card layout. On door exit, the user is redirected back to the door listing.

### Terminal Scaling for Door Games

Door game output now scales across terminal sizes. A DECSTBM scroll region centers 80-column content horizontally and vertically on oversized terminals, with natural scrolling preserved within the centered viewport. Works across all door launch types (NativeShell, ExecNative, SpawnNative, Dosemu, DosemuPty, SyncJS). A per-door `fixed_size` flag in the admin door editor controls which doors get centering.

CP437-to-UTF8 conversion in the output parser now works without byte mangling on raw CP437 terminals. Form feed (0x0C) is intercepted for xterm.js compatibility. The result: any stock Linux terminal can connect and play door games with correct character rendering.

### UTF-8 Encoding Detection Fix

The terminal negotiation UTF-8 detection test was sending 4 bytes instead of 2 due to a JavaScript string encoding issue, causing all terminals to detect as CP437. Fixed to send raw byte array. Added TTYPE-based encoding override for modern terminals (xterm, gnome-terminal, konsole, etc.) as a safety net. UTF-8 charset glyphs and box drawing characters fully populated.

### User Verification System

Email/netmail address verification with 6-digit codes. Auto-sends on registration and address change. Terminal handler in the call flow (skips silently if verified) and as a menu command. Web verification page with send, enter code, change address, and days-remaining countdown. Unverified accounts get a restriction flag and are automatically purged after a configurable retention period.

### Password Reset

Pre-login code-based reset from the logon screen: enter username, receive 8-character code via email/netmail, enter code, set new password. Web flow with clickable token link. Post-login password change via menu command (requires current password). 4-hour token expiry.

### Profile Editing

Username change with configurable cooldown (default 90 days), name, location, gender. Inline password change. Verification status badge with link to verify/change address.

### Admin Improvements

- Jobs & Maintenance page with tabbed manual triggers for all worker jobs
- SMB (Synchronet Message Base) import: upload .shd/.sdt/.sid, preview, import to area
- Announcement and menu entry drag-to-reorder
- Door editor fixed_size toggle
- TinyMCE GPL license key configured

## Getting Started

Download the release source code and extract, or clone the release repo:

```bash
git clone --branch v0.9.1-alpha.1 --depth 1 https://gitlab.tranqsoft.com/drog007/canectic.git
cd canectic
bash setup/install.sh
```

See `docs/sysop/INSTALL.md` for the full walkthrough.

## Upgrading from v0.9.0

```bash
cd /path/to/canectic-source
git pull
bash setup/install.sh /path/to/run-directory
cd /path/to/run-directory
npm install
node src/tools/dbmigrations.js
pm2 restart all
```

New database columns are added automatically by the migration tool. New config keys appear in Admin > Config after restart.

## Known Issues

- ZMODEM file transfers fail with IcyTerm (both directions); all other tested clients work
- Some SyncJS doors may not handle oversized terminals well even without fixed_size (door-specific limitation)
- Web door launcher terminal size is fixed at 80x25 (no resize support yet)
